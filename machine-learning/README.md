# 📊 Ultimate Auto-ML God Mode (V2.0 MAX)

Welcome to the **Machine Learning module (V2.0 MAX)**! This project completely automates Data Analysis and Machine Learning with a jaw-dropping Cyber UI.

## ✨ Jaw-Dropping Features
- **🕵️ Deep Data Dive:** Upload any CSV and instantly see advanced statistics, metric cards, and missing value diagnostics.
- **📈 Interactive Cyber Analytics:** Automatically generates dynamic Correlation Heatmaps and Scatter plots using Plotly Dark Mode.
- **🥊 Multi-Model Showdown:** Pits Random Forest, Gradient Boosting, and Support Vector Machines (SVM) against each other simultaneously!
- **🏆 Model Leaderboard & Export:** Ranks models by Accuracy or RMSE, plots Deep Feature Importance, and lets you download the winning `.pkl` model instantly.
- **🚀 Zero Coding Required:** It's all wrapped in a massive, beautiful Streamlit Web UI.

## 🚀 How to Run

```cmd
cd c:\Github\ai-projects\machine-learning
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

# 🎨 Ultimate Image Forge (V2.0 MAX)

Welcome to the **Generative AI module (V2.0 MAX)**! This project allows you to generate incredibly high-quality, stunning AI art and photorealistic images completely for free.

## ✨ Jaw-Dropping Features
- **⚡ Instant Neural Generation:** Powered by advanced Stable Diffusion endpoints. Zero wait times.
- **🛡️ 100% Hassle-Free:** ZERO API keys required. No complicated setups, no massive GPU downloads required.
- **🎨 Cinematic Art Styles:** Apply professional style modifiers instantly (Photorealistic, Anime, Cyberpunk, Cinematic, 3D Render, Pixel Art).
- **📐 Aspect Ratio Control:** Generate in Square, Portrait, Landscape, or Ultra-Wide (1920x1080) HD.
- **🎲 Seed Manipulation:** Fully control the diffusion noise seed for reproducible masterpieces.
- **🚫 Negative Prompts:** Explicitly tell the AI what *not* to draw.
- **🌌 Jaw-Dropping Cyber UI:** Built with Streamlit for a clean, modern dark-mode interface with progress animations.

## 🚀 How to Run

```cmd
cd c:\Github\ai-projects\generative-ai
python -m venv venv
.\venv\Scripts\activate
```
